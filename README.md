# geno-prime

Prime number helpers in [Geno](https://github.com/davidiach/geno-lang).

## Install

```bash
pip install geno-lang
```

## Test

```bash
geno test Main.geno
```

## Run

```bash
geno run Main.geno
```

## API

- `is_prime(n: Int) -> Bool`
- `next_prime(n: Int) -> Int`
- `primes_up_to(limit: Int) -> List[Int]`
